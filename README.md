# Riemann Hypothesis Exposition

A reader's guide to the claimed Lean proof of the Riemann hypothesis (November 20, 2026), with a check of its formal statement.
Written for readers who know calculus but not analytic number theory.

Author: Zinan Xing

Essay (PDF): [riemann-hypothesis-exposition.pdf](riemann-hypothesis-exposition.pdf)
